# 对标验证与拆解

仅在用户已经提供候选账号、内容、产品、截图、链接或数据时读取。

## 先明确本次决定

常见决定：

- 是否值得继续研究；
- 应对标完整业务还是局部动作；
- 流量为什么没有转化；
- 哪个机制可以迁移；
- 还缺什么证据。

不要为了完整而拆解所有层级。选择能改变本次决定的最小范围。

## 五层拆解

### 1. 赛道层

记录目标用户、核心问题、常见内容、产品形态、价格带、成交场域和代表性差异。区分引流款、利润款和高客单交付。

### 2. 账号层

记录账号主张、受众、人设、信任来源、内容栏目、发布形式、产品入口和组织支持。真实标签与业务相关才有分析价值；标签多不等于变现强。

### 3. 人设／内容层

回答：

- 这个人凭什么谈这个问题；
- 主要对谁说话；
- 反复讨论哪些母题；
- 内容提供什么价值或情绪；
- 身份和表达是否一致；
- 哪些优势来自无法迁移的履历或资源。

### 4. 产品层

还原产品阶梯：

```text
免费内容 → 低门槛验证／引流 → 核心利润产品 → 高客单或持续交付
```

记录每层产品解决的问题、价格、承接入口、交付方式、复购可能和可见证据。无法看到的部分写未知。

### 5. 单篇内容／关键词层

记录封面、标题、目标用户、核心问题、开头、结构、证据、建议、行动引导、承接产品和可见指标。分析关键词对应的人群、情境、情绪、立场和产品，不只收集爆款原句。

## 三重匹配

| 匹配 | 核心问题 | 常见断点 |
| --- | --- | --- |
| 人设—内容 | 这个人说这件事是否可信且相关 | 标签与话题割裂，依赖伪造或无关背书 |
| 内容—产品 | 被内容吸引的人是否需要该产品 | 内容吸引 A 人群，产品服务 B 人群 |
| 流量—成交 | 内容之后是否有自然、可见的下一步 | 没有入口、信任不足、跨度过大或交付不清 |

每项给出「匹配／部分匹配／不匹配／未知」、证据和影响。不要只给标签。

## 还原行动链

按用户能观察到的内容写出：

```text
用户从哪里看见
→ 为什么停留
→ 为什么相信
→ 如何理解产品价值
→ 采取什么下一步
→ 如何成交
→ 如何交付或复购
```

为每个关键动作补充：

- 功能：它解决什么问题；
- 前提：需要什么条件；
- 证据：从哪里看出；
- 失效边界：什么变化会使其失效。

## 代表内容分析

只在用户提供内容样本时使用。至少检查：

- 封面和发布标题是否承诺同一件事；
- 正文是否兑现标题承诺；
- 开头使用什么情境、痛点、冲突或结果；
- 证据来自经历、数据、演示还是社会证明；
- 结尾、评论区、直播、店铺或社群如何承接；
- 可见指标是否有明确分母和时间窗口。

不要使用固定的跨平台「及格线」。没有曝光分母时不要计算点击率，没有新增关注归因时不要声称转粉率。
