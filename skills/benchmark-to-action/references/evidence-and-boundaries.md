# 证据、置信度与边界

在验证商业结果、评价「是否赚钱」、分析他人身份或决定能否借鉴时读取。

## 证据账本

把关键材料分为四类：

| 类别 | 含义 | 写法 |
| --- | --- | --- |
| 事实 | 用户提供或公开来源直接显示的内容 | 写明来源和观察日期（可得时） |
| 信号 | 可能支持结果，但存在其他解释 | 写明它能支持什么、不能证明什么 |
| 推断 | 基于事实和信号得到的条件性判断 | 使用「可能」「更符合」等条件语气 |
| 未知 | 当前材料无法判断 | 说明最小补证方法 |

不要把模型常识、课程观点或用户猜测标成事实。

## 置信度

- **高：** 直接、可核对、与判断高度相关，或多个独立来源一致；
- **中：** 有多个间接信号，但仍缺关键成本、收入或时间口径；
- **低：** 单一弱信号、截图不完整、口径未知或替代解释很多；
- **无法判断：** 缺少决定性信息，继续推断会变成编造。

置信度评价的是当前判断证据，不评价账号或用户本人。

## 分开三种结果

### 内容结果

曝光、点击、观看、互动、收藏、评论、关注等。

### 商业结果

询单、预约、成交、复购、公开产品销售、品牌合作或其他可见承接。

### 利润结果

收入减去获客、交付、人工、退款、平台和其他成本后的结果。公开内容通常无法证明真实利润。

可以说「存在商业化信号」，不要因此写成「确定赚钱」或给出真实利润数字。

## 常见信号的上限

| 信号 | 可以支持 | 不能单独证明 |
| --- | --- | --- |
| 粉丝量 | 账号具备一定受众存量 | 受众活跃、成交或利润 |
| 爆款 | 某内容获得高传播 | 可重复、产品匹配或盈利 |
| 报价 | 存在公开报价或意向 | 实际成交、交付成本或利润 |
| 晒单／评价 | 存在社会证明 | 全部真实、具有代表性或可复现 |
| 店铺销量 | 存在表面销售数据 | 净利润、退款率或自然成交占比 |
| 投放痕迹 | 可能存在付费获客 | 投放回报为正 |
| 多个账号 | 可能存在矩阵运营 | 每个账号都有效或整体盈利 |

## 知识产权与真实性

可借鉴：

- 目标用户与使用情境；
- 选题机制、信息结构和商业功能；
- 产品阶梯与验证方法；
- 指标体系和复盘问题。

不可直接复制：

- 原文、口播、标题、封面文字和视觉构图；
- 图片、视频、音乐、设计素材和商标；
- 个人经历、身份、人设、案例和用户评价；
- 容易使受众误认来源或关联关系的包装。

不得建议伪造履历、销量、评论、客户或经营数据。

## 隐私与权限

- 只分析用户提供或合法公开的信息；
- 不索取、抓取、推断或披露私人聊天、成员名单、买家 IP、联系方式或未公开经营数据；
- 不绕过登录、付费墙、访问控制或平台限制；
- 用户只要求分析时，不替其联系博主、商家或消费者；
- 需要当前平台规则时，核验官方来源；无法核验则明确时效风险。

## 结论句式

优先使用：

- 「当前材料直接显示……」
- 「这构成……的中等信号，但不能证明……」
- 「更符合……，置信度为低／中／高，原因是……」
- 「真实利润未知；最小补证是……」
- 「可以借鉴的是……的功能，不能复制的是……的具体表达。」

避免使用：

- 「他肯定赚钱。」
- 「照着做就能复制利润。」
- 「这个数据证明产品一定好卖。」
- 「平台就是喜欢这种内容。」
