# 小红书参考

仅在用户提供小红书账号、笔记、店铺或小红书相关目标时读取。本文件提供分析字段，不保存易过时的开通门槛、平台偏好或固定指标阈值。

## 可观察层面

根据用户提供或合法公开的材料选择：

- 账号简介、人设标签和内容分类；
- 图文／视频笔记、封面、发布标题、正文和标签；
- 点赞、收藏、评论等页面可见互动；
- 直播、店铺、商品、小清单、群聊或其他公开入口；
- 评论区中的公开行动引导；
- 公开展示的品牌合作或商业化信号。

不要索取私人聊天、群成员、买家信息、后台数据或非公开联系方式。

## 双标题与承诺兑现

图文笔记通常同时存在封面文案和发布标题。分别记录：

- 两者是否面向同一用户问题；
- 关键词是否重复或补充；
- 正文是否兑现承诺；
- 是否存在夸大、歧义或与正文无关的吸引。

分析结构时不要复用原句。把原句转化为「目标用户 + 情境 + 冲突／结果 + 证据类型」等抽象变量。

## 内容结构

可按需观察：

- 开头使用痛点、场景、反差、结果还是问题；
- 正文如何组织经历、证据、方法和建议；
- 图片或视频承担什么信息功能；
- 标签如何描述人群、主题或场景；
- 评论区、直播、群聊、店铺或私信提示如何承接下一步。

## 指标

只计算有可靠分母和时间窗口的指标：

- 点赞率、收藏率、评论率需要可比的浏览或曝光分母；
- 点击率需要曝光和点击数据，公开页面通常不完整；
- 转粉率需要新增关注的归因数据，账号总粉丝不能替代；
- 完播率、完读率和人均观看时长通常需要后台数据。

如果只有页面可见数字，可以做同账号、相近发布时间和相同内容形态的相对比较；不要套用固定的跨账号「8% 及格线」。

## 关键词库

为每个关键词记录：

| 字段 | 内容 |
| --- | --- |
| 关键词 | 平台标签、相关搜索或对标反复使用的词 |
| 对应人群 | 谁可能搜索或点击 |
| 用户情境 | 正在经历什么 |
| 情绪／立场 | 焦虑、期待、复盘、支持、反对等 |
| 内容样本 | 哪类内容使用过，不复制原句 |
| 产品连接 | 该人群可能需要什么产品；未知时不强连 |
| 用户证据 | 用户本人有什么真实经历、案例或材料 |
| 独立选题 | 重新创作的测试方向 |

## 时效性

小红书的商业入口、开通条件、页面字段和平台规则会变化。用户询问当前门槛或规则时，优先核验官方当前信息；无法核验时说明日期和不确定性，不沿用未经核验的旧资料。
