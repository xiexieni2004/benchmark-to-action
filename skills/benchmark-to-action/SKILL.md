# 对标转行动

把商业对标从「看起来值得学」转化为有证据、有边界、符合用户条件的行动实验。

## 不变量

1. **只教找法，不替用户找人。** 可以设计搜索方向、关键词、渠道、筛选条件和记录表；不得主动搜索、推荐或点名实际对标。用户提供候选后，可以验证和拆解该候选。
2. **分开内容结果与商业结果。** 流量、粉丝、互动、报价或晒单只是信号，不等于收入，更不等于利润。
3. **区分证据与推断。** 将关键判断标为事实、信号、推断或未知；证据不足时保留未知并给出补证方法。
4. **分析完整链条。** 不只看标题和封面，还要检查目标用户、人设、内容、产品、成交与交付如何连接。
5. **借鉴机制，不复制表达。** 可以抽象选题机制、信息结构、商业功能和验证方法；不得仿写原文、复刻视觉、冒用身份或制造混淆。
6. **适配用户条件。** 比较双方资源、能力、产品和渠道；为无法照做的环节设计功能等价的替代动作。
7. **用实验收尾。** 个性化建议至少包含下一步动作、观察指标、时间或样本范围，以及风险上限或停止条件。

## 选择模式

根据用户当前要推进的变化选择最小模式。混合请求可以顺序执行，但不要强迫用户阅读完整报告。

### 模式 A：制定寻找与筛选策略

适用于用户没有候选，询问到哪里找、搜索什么、如何筛选。

- 不浏览平台寻找具体账号，不输出候选名单。
- 读取 [references/finding-strategy.md](references/finding-strategy.md)。
- 输出对标规格、搜索矩阵、筛选门槛、证据收集表和停止条件。

### 模式 B：验证与拆解用户提供的对标

适用于用户提供账号、链接、截图、内容、产品或已知数据，希望判断是否值得研究或理解其机制。

- 读取 [references/evidence-and-boundaries.md](references/evidence-and-boundaries.md)。
- 读取 [references/deconstruction.md](references/deconstruction.md)。
- 涉及小红书时，再读取 [references/xiaohongshu.md](references/xiaohongshu.md)。
- 只检查用户提供的候选和完成判断所必需的来源，不扩展为替用户寻找更多对标。

### 模式 C：转化为用户自己的行动

适用于用户已经有对标，但因资源、能力或场景不同而不会执行，或希望形成自己的实验。

- 读取 [references/evidence-and-boundaries.md](references/evidence-and-boundaries.md)。
- 读取 [references/action-adaptation.md](references/action-adaptation.md)。
- 如果尚未理解候选的商业链，先按模式 B 做必要拆解。
- 输出行动链、差距、替代动作和最小实验，而不是相似成品。

## 最少输入与提问

优先从当前对话和用户材料中恢复信息，不重复询问。

- 模式 A 至少需要：用户想进入或增长的领域，以及希望得到的结果。
- 模式 B 至少需要：一个由用户提供的候选或候选材料，以及用户想判断的问题。
- 模式 C 还需要：用户自己的产品／目标、可用资源、主要限制；未知项可以显式假设。

只有缺少的信息会改变模式、关键判断或实验可行性时，才合并为一个简短问题。否则继续工作并标注假设。

## 共同工作方式

1. **定义决定。** 先说明本次要决定什么，例如「是否值得拆」「哪里断裂」「下一步测试什么」。
2. **建立证据账本。** 分开记录公开事实、结果信号、推断和未知项；注明材料日期或观察时间（可得时）。
3. **选择拆解层级。** 只分析当前需要的赛道、账号、人设／内容、产品、单篇内容／关键词层级。
4. **检查三种匹配。** 检查人设—内容、内容—产品、流量—成交；说明证据和断点。
5. **解释动作功能。** 对关键动作写清它解决什么问题、依赖什么条件、何时失效。
6. **比较用户条件。** 标出已有、缺少和暂时不会的资源或能力。
7. **生成独立实验。** 保留机制，重新设计具体表达和执行形式；给出指标与停止条件。

## 输出要求

根据模式输出必要模块，避免空洞长报告。

- **策略模式：** 对标规格、搜索矩阵、用户自行执行的搜寻步骤、筛选表、何时停止搜索。
- **拆解模式：** 判断摘要、证据账本、必要层级拆解、三重匹配、可借鉴机制、不可复制部分、未知项。
- **行动模式：** 关键行动链、用户差距、功能等价替代、最小实验、指标、风险上限和复盘问题。

任何关于「赚钱」「有效」「适合」的结论都必须带证据强度或条件。无法判断时写「未知」，不要使用确定语气填补空白。

## 停止条件

- 没有用户提供的候选时，模式 A 停在搜寻与筛选策略，不自行进入实际搜索。
- 候选材料不足以判断商业结果时，停在分级推断并列出最小补证清单。
- 用户要求复制具体作品时，停止相似化输出，改为抽象机制和独立实验。
- 用户条件不足以执行原路径时，不要求硬抄；提供功能等价替代，或说明当前无法安全验证。
- 继续分析只会重复同一证据、扩大未经证实的猜测或越过隐私／权限边界时结束。
- 发布、联系、购买、投流或其他外部动作需要用户单独授权；分析请求本身不授权执行这些动作。
